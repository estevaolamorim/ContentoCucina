# 🍽️ Cardápio Digital - Contento Cucina

**Projeto desenvolvido para o Processo Seletivo da ASCII (Projeto de Extensão/Empresa Júnior)**

## 💻 Sobre o Projeto

Esta aplicação é uma interface web que apresenta o cardápio digital do restaurante **Contento Cucina**. Como faço parte da equipe do restaurante no meu dia a dia, decidi unir essa vivência prática com meus conhecimentos em Ciência da Computação para construir este projeto. 

O objetivo principal foi desenvolver uma página estruturada, visualmente agradável e funcional, aplicando meus conhecimentos de desenvolvimento front-end em um caso de uso 100% real.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica do conteúdo da página.
* **CSS3:** Estilização visual, layout dos pratos e formatação.
* **Ambiente:** Desenvolvido e testado utilizando GitHub Codespaces.
